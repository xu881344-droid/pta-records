## 收录规则

- 只有评测结果为「答案正确」的题目才会生成代码文件。
- 同一道题提交多次且都 AC 时，取**最后一次**（即最终定稿的版本）。
- 错误的、部分正确的、编译错误的尝试一律不收录。

## 目录结构

```
index.md              已通过题目清单（按题目集分组，带得分与代码链接）
problems/<NN-题目集>/<题号>-<标题>.c    最终通过版源码
data/problems.json    已收录题目的元数据（得分 / 提交时间 / 提交 ID / 原题链接）
data/pending.json     尚未通过的题目（只记清单，不含代码）
```
